# go-fragment

Неофициальный клиент [Fragment](https://fragment.com) на Go. Им ищут Telegram-получателя и покупают ему Stars или дарят Premium. Оплату подписывает кошелёк вызывающего.

Fragment это API не публикует. Пакет не связан с Telegram, TON и любой витриной. GGSEL и другие кассы остаются снаружи: они сами передают `@username`, сумму и свой ключ идемпотентности. Вебхука, доставки заказа и префикса ключа в модуле нет.

Лицензия MIT.

## Установка

```bash
go get github.com/andhash/go-fragment
```

Нужен Go 1.23 или новее.

## Граница

Вызывающий приносит сессию Fragment и мнемонику горячего кошелька. Мнемоника не уходит с машины. Cookie уходят только на `fragment.com`. Основной кошелёк сюда не подключают: на горячем лежит сумма ближайших покупок.

Скрытой комиссии нет. Чужой пакет `fragment-api-py` 14.4.2 умел перевести средства с подключённого кошелька. Этот модуль так не делает и seed никуда не отправляет.

Спецификация плательщика — [DESIGN.md](DESIGN.md). Кода покупки в этом коммите ещё нет: репозиторий фиксирует модуль `github.com/andhash/go-fragment` и границу «библиотека Fragment, не интеграция витрины».
